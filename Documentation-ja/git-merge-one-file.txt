git-merge-one-file(1)
=====================

NAME
----
git-merge-one-file - git-merge-indexで使用する標準のヘルパープログラム


SYNOPSIS
--------
[verse]
'git merge-one-file'

DESCRIPTION
-----------
これは、 'git merge-index' で行われた簡単なマージの後にマージを解決するために、 'git read-tree -m' で使用する標準のヘルパープログラムです。
