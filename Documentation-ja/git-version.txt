git-version(1)
==============

NAME
----
git-version - Gitに関するバージョン情報を表示する

SYNOPSIS
--------
[synopsis]
'git version' [--build-options]

DESCRIPTION
-----------
オプションが指定されていない場合、 `git` のバージョンが標準出力に出力されます。

`git --version` は `git version` と同じであることに注意してください。これは、前者が内部で後者に変換されるためです。

OPTIONS
-------
`--build-options`::
	診断目的でgitがどのように構築されたかに関する追加情報を含めます。
