git-init-db(1)
==============

NAME
----
git-init-db - 空のGitリポジトリを作成


SYNOPSIS
--------
[synopsis]
	'git init-db' [-q | --quiet] [--bare] [--template=<template-directory>] [--separate-git-dir <git-dir>] [--shared[=<permissions>]]


DESCRIPTION
-----------

これは linkgit:git-init[1] の同義語です。 linkgit:git-init[1] コマンドの文書を参照してください。
