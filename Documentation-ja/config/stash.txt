stash.showIncludeUntracked::
	これがtrueに設定されている場合、 `git stash show` コマンドはstashエントリの追跡されていないファイルを表示します。 デフォルトはfalseです。 linkgit:git-stash[1] の showコマンドの説明を参照してください。

stash.showPatch::
	これがtrueに設定されている場合、オプションのない `git stash show` コマンドは、パッチ形式でstashエントリを表示します。 デフォルトはfalseです。 linkgit:git-stash[1]の showコマンドの説明を参照してください。

stash.showStat::
	これがtrueに設定されている場合、オプションのない `git stash show` コマンドは、stashエントリのdiffstatを表示します。 デフォルトはtrueです。 linkgit:git-stash[1] の showコマンドの説明を参照してください。
