interactive.singleKey::
	対話コマンドでは、ユーザーが1つのキーで1文字の入力を提供できるようにします(つまり、Enterキーを押さずに)。 現在、これは linkgit:git-add[1] と linkgit:git-checkout[1] と linkgit:git-restore[1] と linkgit:git-commit[1] と linkgit:git-reset[1] と linkgit:git-stash[1] の `--patch` モードで使用されています。 ポータブルキーストローク入力(portable keystroke input)が利用できない場合、この設定は黙って無視されることに注意してください。 Perlモジュール Term::ReadKey が必要です。

interactive.diffFilter::
	対話コマンド(`git add --patch` など)が色付きのdiffを表示すると、gitはこの構成変数で定義されたシェルコマンドを介してdiffをパイプします。 コマンドは、元のdiffの行と1対1の対応を保持している場合、人間に読みやすいようにdiffをさらにマークアップできます。 デフォルトは無効(フィルタリングなし)です。
