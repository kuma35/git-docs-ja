help.browser::
	ヘルプをweb形式で表示するために使用されるブラウザーを指定します。 linkgit:git-help[1] を参照してください。

help.format::
	linkgit:git-help[1] で使用されるデフォルトのヘルプ形式を上書きします。 値として `man` と `info` と `web` と `html` がサポートされています。 `man` がデフォルトです。 `web` と `html` は同じ(same)です。

help.autoCorrect::
	gitがタイプミスを検出し、間違いにに類似した有効なコマンドを1つだけ識別できる場合、gitは正しいコマンドを提案しようとするか、提案を自動的に実行します。 可能な構成値は以下のとおりです:
	* 0, `false`, `off`, `no`, `show`: コマンドを提案(表示)するだけ(デフォルト)。
	* 1, `true`, `on`, `yes`, `immediate`: 提案したコマンドを即座に実行する。
	* 1より大きい正の数(positive number > 1): 指定のデシ秒(0.1秒単位)の遅延後に提案したコマンドを実行する。
	* "never": 提案したコマンドの表示はしないし実行もしません。
	* "prompt": コマンドを実行するための提案と確認のプロンプトを表示します。

help.htmlPath::
	HTMLドキュメントが存在するパスを指定します。 ファイルシステムのパスとURLがサポートされています。 ヘルプが「web」形式で表示される場合、HTMLページの前にこのパスが付けられます。 これはデフォルトでGitインストールのドキュメントパスになります。
