rerere.autoUpdate::
	When set to true, `git-rerere` updates the index with the resulting contents after it cleanly resolves conflicts using previously recorded resolutions. Defaults to false.

rerere.enabled::
	解決された競合の記録をアクティブにして、同じ競合ハンクが再度発生した場合に自動的に解決できるようにします。 デフォルトでは、 `$GIT_DIR` の下に `rr-cache` ディレクトリがある(例えば `rerere` が以前にリポジトリで使用されていた)場合、 linkgit:git-rerere[1] が有効になります。
