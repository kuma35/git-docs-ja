`init.templateDir`::
	テンプレートのコピー元のディレクトリを指定します。 {see-git-init}
`init.defaultBranch`::
	デフォルトのブランチ名を上書きできます。例えば、新しいリポジトリを初期化するとき。
`init.defaultObjectFormat`::
	新しいリポジトリのデフォルトのオブジェクト形式をオーバーライドできるようにします。 linkgit:git-init[1] の `--object-format=` を参照してください。 コマンド・ライン・オプションと `GIT_DEFAULT_HASH` 環境変数の両方とも、 この設定より優先されます。
`init.defaultRefFormat`::
	新しいリポジトリのデフォルトの ref ストレージ形式をオーバーライドできるようにします。 linkgit:git-init[1] の `--ref-format=` を参照してください。 コマンド・ライン・オプションと `GIT_DEFAULT_REF_FORMAT` 環境変数の両方とも、 この設定より優先されます。
