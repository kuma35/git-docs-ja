git-hook(1)
===========

NAME
----
git-hook - git のフック達を実行

SYNOPSIS
--------
[synopsis]
	'git hook' run [--ignore-missing] [--to-stdin=<path>] <hook-name> [-- <hook-args>]

DESCRIPTION
-----------

他のスクリプト化された git コマンドで使用する、 Git のフックを実行するためのコマンド・インターフェイス(linkgit:githooks[5] 参照)。

SUBCOMMANDS
-----------

run::
	`<fook-name>` のフックを実行します。 サポートされているフック名については、 linkgit:githooks[5] を参照してください。
+

フックへの位置引数は、 必須の `--` (または `--end-of-options` (linkgit:gitcli[7] 参照))の後ろで渡す必要があります。 フックが期待する引数(もしあれば)については linkgit:githooks[5] を参照してください。

OPTIONS
-------

`--to-stdin`::
	「run」の場合、 フックの stdin にストリームされるファイルを指定してください。 フックは、 ファイルの先頭からEOFまでの全体を受け取ります。

`--ignore-missing`::
	フックが存在しない場合は静かにゼロを返して無視します。 フックが存在するかどうかにかかわらず、 一度だけ実行したいツールで使用されます。
