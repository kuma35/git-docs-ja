git-hook(1)
===========

NAME
----
git-hook - gitフックの実行

SYNOPSIS
--------
[verse]
'git hook' run [--ignore-missing] [--to-stdin=<path>] <hook-name> [-- <hook-args>]

DESCRIPTION
-----------

他のスクリプト化された git コマンドで使用するための、 git フック(linkgit:githooks[5] 参照) を実行するためのコマンド・インターフェイス。

SUBCOMMANDS
-----------

run::
	`<hook-name>` フックを実行します。 サポートされているフック名については、 linkgit:githooks[5] を参照してください。
+

フックへの位置引数は、 必須の `--` (または `--end-of-options` については linkgit:gitcli[7] 参照)の後ろで渡す必要があります。 フックが期待する引数(存在する場合)については、 linkgit:githooks[5] を参照してください。

OPTIONS
-------

`--to-stdin`::
	"run" 用。 フックの標準入力に流し込まれるファイルを指定します。 フックはファイル全体を先頭から EOF まで受け取ります。

`--ignore-missing`::
	見つからないフックを無視し、黙ってゼロを返します。 存在するかどうかわからないフックを一発で実行したいツールに使用します。
