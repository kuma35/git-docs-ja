git-version(1)
==============

NAME
----
git-version - Gitに関するバージョン情報を表示する

SYNOPSIS
--------
[synopsis]
	'git version' [--build-options]

DESCRIPTION
-----------
オプションが指定されていない場合、 `git` のバージョンが標準出力に出力されます。

`git --version` は `git version` と同じであることに注意してください。これは、前者が内部で後者に変換されるためです。

OPTIONS
-------
`--build-options`::
	診断目的でgitがどのように構築されたかに関する追加情報を含めます。
+
SHA-1 および SHA-256 アルゴリズムを実装するために使用されるライブラリは、`SHA-1: <option>` および `SHA-256: <option>` の形式で表示されます。 SHA-1 のオプション `SHA1_APPLE` 、 `SHA1_OPENSSL` 、 `SHA1_BLK` は衝突検出アルゴリズムを使用しないため、既知の SHA-1 衝突攻撃(collision attacks)に対して脆弱である可能性があることに注意してください。 衝突検出を行わないより高速な SHA-1 実装が暗号目的ではない用途にのみ使用される場合、アルゴリズムは `non-collision-detecting-SHA-1: <option>` の形式で表示されます。
