git-verify-tag(1)
=================

NAME
----
git-verify-tag - タグのGPG署名を確認する

SYNOPSIS
--------
[verse]
'git verify-tag' [-v | --verbose] [--format=<format>] [--raw] <tag>...

DESCRIPTION
-----------
`git tag` によって作成されたgpg署名を検証します。

OPTIONS
-------
`--raw`::
	通常の人間が読める形式の出力の代わりに、生のgpgステータス出力を標準エラーに出力します。

`-v`::
`--verbose`::
	検証する前に、タグオブジェクトの内容を出力します。

<tag>...::
	GitタグオブジェクトのSHA-1 ID。
