git-verify-pack(1)
==================

NAME
----
git-verify-pack - パックされたGitアーカイブファイルを検証する


SYNOPSIS
--------
[synopsis]
	git verify-pack [-v | --verbose] [-s | --stat-only] [--] <pack>.idx...


DESCRIPTION
-----------
コマンドラインで指定されたパックされたGitアーカイブの各idxファイルを読み取り、idxファイルと対応するパックファイルを検証します。

OPTIONS
-------
`-v`::
`--verbose`::
	パックを確認した後、パックに含まれるオブジェクトのリストとデルタチェーン長のヒストグラムを表示します。

`-s`::
`--stat-only`::
	パックの内容を確認せず、デルタチェーン長のヒストグラムのみを表示します。 `--verbose` を使用すると、オブジェクトのリストも表示されます。

`--`::
	これ以降の引数をオプションとして解釈しないでください。

OUTPUT FORMAT
-------------
オプション `-v` を指定する場合、使用される形式は以下のとおりです:

	object-name type size size-in-packfile offset-in-packfile

は、パックで削除されていないオブジェクトの場合です。そして、

	object-name type size size-in-packfile offset-in-packfile depth base-object-name

は、削除されたオブジェクトの場合です。
