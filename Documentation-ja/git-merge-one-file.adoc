git-merge-one-file(1)
=====================

NAME
----
git-merge-one-file - git-merge-indexで使用する標準のヘルパープログラム


SYNOPSIS
--------
[synopsis]
`git merge-one-file`

DESCRIPTION
-----------
これは、 `git merge-index` で行われた些細なマージ(trivial merge)の後でマージを解決するために、 `git read-tree -m` と一緒に使用する標準的なヘルパー・プログラムです。
